## 使用

需要在 Codex 使用这套偏好时，将本目录 `AGENTS.md` 的内容复制到全局
`~/.codex/AGENTS.md`。它是供手动选用的模板，收录操作不会修改本机配置，也不会随模型选择自动切换。

- 输入：用户任务及项目规则。
- 输出：遵循上述偏好的回答和开发行为。
- 依赖：`rg`、[dev-review-collab](../../../skills/engineering/dev-review-collab/SKILL.md)。简单任务按该技能的适用范围由当前代理直接完成。
- 条件依赖：项目含 `.catpaw/` 时，需有本机 `~/.catpaw/runtime-policy.md`。
- 使用边界：这是面向 GPT 6.1 Sol 的个人配置，不是模型能力要求；迁移到其他环境时需先适配技能和运行时依赖。验证与授权按正文及适用项目规则执行。
