# Anthropic Animation

Creates promotional, educational, and product explainer animations with warm
paper colors, editorial typography, and restrained motion inspired by Anthropic.
Use when this visual direction fits the brief while storyboards, visual
metaphors, pacing, and composition should be designed freely for the content.

- Entry point: [SKILL.md](SKILL.md).
- Dependency: a web browser for HTML animation playback; fonts and optional
  media assets depend on the chosen implementation.
- Inputs: animation brief, audience, communication goals, source materials,
  and visual or delivery constraints.
- Outputs: an editable HTML file or folder with supporting assets, automatic
  playback, pause and replay controls, plus entry file, duration, and audio notes.
- Boundaries: ground factual claims in user materials and distinguish illustrative
  scenes from real demonstrations. Deliver editable HTML first, including when
  the brief calls it a promotional video; export MP4 only when explicitly requested
  later. Default to 1920x1080 when no aspect ratio is specified.
